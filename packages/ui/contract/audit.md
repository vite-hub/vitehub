# Props contract audit

One row for each component family of `api.json`: the API today, the API after its plan unit applies `CONTRACT.md`, and what breaks. The unit column names the plan unit that owns the change. Each break is also a row in `migrations.ts`, so `vitehub migrate` can rewrite it. `test/contract.test.ts` fails when a component of `api.json` is missing from this file.

U3 builds the base items (button, icon, input, field, tooltip, skeleton, empty, alert, badge, card, kbd, sidebar). They are not in `api.json` yet, because `@vite-hub/ui` does not export them today. U2 converts the three pilots (`Status`, `CopyButton`, `PromptInput`) first. Their target is the same as the rows below.
