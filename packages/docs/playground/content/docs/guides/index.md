Each guide does one task from start to end. Read [Getting started](/docs/getting-started) first if Lumen is new to you.

::illustration{name="guides" alt="Image frames with crop marks, a clamp that squeezes a picture, and format plates for WebP and AVIF."}
::

::product-features
  :::product-feature-item{title="Resize images" icon="i-lucide-scaling" to="/docs/guides/resize"}
  Set a largest width, keep the aspect ratio, and make responsive sizes.
  :::

  :::product-feature-item{title="Compress images" icon="i-lucide-file-down" to="/docs/guides/compress"}
  Pick a quality, compare the results, and keep the originals.
  :::

  :::product-feature-item{title="Convert formats" icon="i-lucide-repeat" to="/docs/guides/formats"}
  Add WebP and AVIF copies, and choose the format per folder.
  :::

  :::product-feature-item{title="Presets" icon="i-lucide-layers" to="/docs/guides/presets"}
  Name a set of settings and use it in many projects.
  :::

  :::product-feature-item{title="Check images in CI" icon="i-lucide-shield-check" to="/docs/guides/ci"}
  Fail a pull request that adds an image that is too large.
  :::
::
