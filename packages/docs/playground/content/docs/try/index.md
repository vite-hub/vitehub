These pages show the two workspace layouts of `@vite-hub/docs`. Each page sets the workspace in its frontmatter. On a phone, each page shows its text instead.

::product-features
  :::product-feature-item{title="Playground" icon="i-lucide-square-terminal" to="/docs/try/playground"}
  Two small Node servers. Pick one, edit it, and see the change in the preview.
  :::

  :::product-feature-item{title="Your first server" icon="i-lucide-graduation-cap" to="/docs/try/first-server"}
  A lesson in two steps. Each step has its own files, and Solve writes the answer.
  :::

  :::product-feature-item{title="Render in the page" icon="i-lucide-file-code" to="/docs/try/render"}
  A playground without a WebContainer. The page renders the HTML file on every device.
  :::
::
