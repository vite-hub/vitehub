## This site is a demo

Lumen is a made-up tool. This site shows [`@vite-hub/docs`](https://vitehub.dev/docs/docs-site): every docs page is a Markdown file in [`packages/docs/playground`](https://github.com/vite-hub/vitehub/tree/main/packages/docs/playground) of vite-hub/vitehub, and the [blog](/blog) and the [changelog](/changelog) are collections of the ViteHub CMS. Signed-in editors change them in the ViteHub Console, leave comments, and let their coding agent edit them through MCP. Read [Edit this site](/docs/this-site) to try it.
