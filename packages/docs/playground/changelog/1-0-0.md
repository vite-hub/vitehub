Lumen 1.0 resizes, compresses, and converts a folder of images in one command, and reads its settings from `lumen.config.json`.

## Added

- `lumen compress`, `lumen resize`, `lumen convert`, and `lumen check`.
- WebP and JPEG output.
- One static binary for macOS, Linux, and Windows, also on npm as `lumen-cli`.
