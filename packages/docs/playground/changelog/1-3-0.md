## Added

- AVIF output with `formats: ["avif"]`. On the Lumen test set, AVIF files are 31% smaller than WebP files at the same visual quality.
- `lumen check` reads `maxSize` from `lumen.config.json`, so CI and your machine use the same limit.

## Changed

- WebP encoding uses all CPU cores. A folder of 500 photos compresses in 41 seconds instead of 2 minutes and 10 seconds on a 10-core laptop.
