## Changed

- AVIF encoding splits each image into tiles on one shared thread pool. A folder of 500 mixed photos encodes in 2 minutes and 51 seconds instead of 9 minutes.

## Fixed

- AVIF encoding of images wider than 8,192 pixels stopped with exit code `2`. Lumen now encodes them in tiles.
- `lumen check` counted `.lumen/originals/` when `keep` was on. It now skips that folder.
- The `--dry-run` report showed `0 B` saved for files that `skip` matched. It now lists them as skipped.
