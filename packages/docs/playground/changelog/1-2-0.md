## Added

- `extends` in `lumen.config.json` starts from a preset. Lumen has three: `lumen:web`, `lumen:thumbnails`, and `lumen:print`.
- Publish your own preset as a package, such as `extends: "@acme/lumen-preset"`.

## Breaking

- The default `maxWidth` is now `1600` instead of `2048`. Set `maxWidth: 2048` to keep the old size.
