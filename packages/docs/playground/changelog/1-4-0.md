## Added

- `lumen compare <path>` opens a local page that shows each original beside its result, with a slider and the byte savings. It changes no file.
- `--format markdown` prints the report as a Markdown table, ready for a pull request comment.

## Changed

- The text report sorts files by bytes saved, largest first.

## Fixed

- `lumen resize` kept the EXIF orientation of a rotated JPEG and wrote it sideways. It now applies the orientation before it resizes.
