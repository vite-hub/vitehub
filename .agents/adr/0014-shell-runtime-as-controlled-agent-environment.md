# Shell Runtime as Controlled Agent Environment

`@vitehub/shell` will be redesigned around a provider-agnostic **Shell Runtime** for agent work in a controlled Unix-like environment, not as a Workspace command helper or a thin `exec()` utility. The primary interaction model is a stateful **Shell Session** that emits rich **Shell Observations**, applies **Shell Session Policy**, declares a **Shell Boundary**, and runs through built-in **Execution Providers** such as Just Bash and Cloudflare exposed on provider subpaths. This is a deliberate breaking public-surface cleanup while the package is pre-1.0: Workspace integration becomes an adapter, callers own final **Policy Decisions**, and the Shell core stays runtime-focused so provider, Workspace, and model-facing tool concerns do not define the package's primary concept.
