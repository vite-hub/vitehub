# Sandbox

Use Sandbox to run a named project in an isolated Cloudflare or Vercel environment. A Sandbox Run is an execution boundary, not a general-purpose local shell.

Read the [Sandbox guide](https://vitehub.dev/docs/sandbox), then [Get started](https://vitehub.dev/docs/sandbox/get-started), [Configure](https://vitehub.dev/docs/sandbox/configure), [Server API](https://vitehub.dev/docs/sandbox/server-api), [Agent Capability](https://vitehub.dev/docs/sandbox/agent-capability), or [Hosts](https://vitehub.dev/docs/sandbox/hosts).

Keep images, mounts, network access, timeouts, and resource bounds explicit. Pass only the files and secrets the run needs.

Prove successful execution, cancellation, timeout, output limits, and cleanup on the selected provider. Inspect generated bindings and provider output.
