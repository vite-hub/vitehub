---
title: Contact ViteHub
description: Where to ask for ViteHub help, report bugs and security issues, and fix the docs.
---

ViteHub is an open-source project. It has no sales desk, paid support, or hosted customer accounts. Pick the channel that fits your need, so maintainers get enough context and sensitive data stays out of public threads.

## Questions and implementation help

Ask in the [ViteHub Discord community](https://chat.vitehub.dev) for help with code, design, or choosing between Server Primitives and Agents. Include your ViteHub version, host or framework, the expected behavior, and a small example if you can. Remove tokens, personal data, private code, and provider credentials before you post.

## Bugs and documentation

Open a [GitHub issue](https://github.com/vite-hub/vitehub/issues) for a bug you can reproduce or a gap in the docs. Search existing issues first. Then describe what happened, what you expected, and the smallest command or repository that shows it. You can also send doc fixes as pull requests.

## Security reports

Do not post a possible vulnerability in Discord or a public issue. Follow the [ViteHub security policy](https://github.com/vite-hub/vitehub/security/policy) to open a private channel before you share the report or proof. Include the affected versions and a safe reproduction. Do not include credentials or data from systems you do not own or may not test.

ViteHub has no support phone number or postal address. If the project gets a legal entity, mailing address, or support email, update this page and the site's structured identity data together.
