Start with [Installation](/docs/getting-started/installation), then run one
route locally before choosing production resources. ViteHub enables only the
features you select.

## Choose your framework and host

Use the [Nuxt module](/docs/frameworks-hosts/nuxt) in a Nuxt application.
Use [Nitro and Vite](/docs/frameworks-hosts/nitro-unjs) when you configure the
server build yourself. The [framework and host overview](/docs/frameworks-hosts)
explains presets and the default providers for each feature.

When you are ready to deploy, open the guide for
[Cloudflare](/docs/frameworks-hosts/cloudflare),
[Vercel](/docs/frameworks-hosts/vercel),
[Netlify](/docs/frameworks-hosts/netlify),
[Deno](/docs/frameworks-hosts/deno), or
[Node](/docs/frameworks-hosts/node-self-hosted).
Read [Production](/docs/frameworks-hosts/production) before connecting real
resources.

## Inspect your app while you build

The [development tools](/docs/development) help you inspect discovered
Definitions and generated output. Use the [CLI](/docs/development/cli) from
a terminal, or the [Console](/docs/development/console) to inspect local runs.
Read [Troubleshooting](/docs/development/troubleshooting) when an integration
or provider fails.

## Check the exact contract

The [shared reference](/docs/reference) covers configuration, import paths,
file conventions, runtime events, and diagnostics. For a feature's API, open
that feature in the left rail and choose its Server API page.
